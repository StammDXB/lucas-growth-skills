# Rubric: Short-Form Video

Score every line PASS or FAIL. No partial credit. Quote evidence from your own
output. Burden of proof is on PASS.

## A. Brief

**A1. One thing, not a list.**
The piece lands a single message. FAIL if it carries two.

**A2. Register was chosen deliberately.**
Premium versus direct-response is stated with reasoning. FAIL if it defaulted
silently.

**A3. One CTA, or explicitly none.**
Two CTAs is a FAIL.

## B. Script

**B1. Three simultaneous hooks.**
Visual, verbal and text hooks all specified for the first three seconds. Missing
any one is a FAIL.

**B2. Every beat is mapped to seconds.**
FAIL on beats with no time window.

**B3. Text hook is five words or fewer.**
Longer will not be read at scroll speed.

**B4. Every line is marked VO or TEXT.**

**B5. The hook is not reusable.**
Substitute a competitor. If the hook still works, FAIL.

**B6. VO leaves room for the visual.**
More than three VO lines across a 20-second piece is a FAIL unless justified.

## C. Storyboard

**C1. A single visual theme is locked.**
Palette, lighting, lens, film look, motion language. Missing any is a FAIL.

**C2. The motion language names what is banned**, not only what is allowed.
"Cinematic" alone is a FAIL.

**C3. One main action per shot.**
Any shot stacking subject plus camera plus environment motion is a FAIL.

**C4. Shot scale varies.**
Four shots at the same scale is a FAIL.

**C5. The hook image lands in the first second.**

**C6. Shot count fits the duration.**
Under three seconds per shot is a FAIL unless deliberate and justified.

## D. Prompts

**D1. One style suffix, identical across every shot.**
Any drift between shots is a FAIL.

**D2. Prompt anatomy is followed in order.**

**D3. No text, captions, or logos in any prompt.**

**D4. No model name or duration inside the prompt text.**

**D5. Single line per prompt, no line breaks.**

**D6. Each prompt contains at least one motion cue.**
Static descriptions return near-still video. FAIL.

**D7. Concrete over generic.**
Each prompt names at least one specific material, texture, or object. FAIL on
keyword soup.

## E. Integrity

**E1. Commercial safety is flagged where relevant.**
Paid usage or implied real likeness raises the issue. FAIL if unaddressed.

**E2. No invented brand facts.**
Zero fabricated locations, inclusions, prices, or claims.

**E3. Assumptions disclosed.**

## Scoring

Fix all FAILs, re-score. Maximum two rounds. Report anything still failing
plainly rather than looping.
