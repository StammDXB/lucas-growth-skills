# Rubric: Campaign Concept

Score every line PASS or FAIL. No partial credit. Quote evidence. Burden of
proof is on PASS.

## A. Foundation

**A1. The audience is specific and their current belief is stated.**
A demographic is not an audience. PASS requires a role, a context, and what they
currently think or do.

**A2. The insight is a tension, not an observation.**
FAIL if the audience would respond "yes, obviously." PASS requires something
they would recognise but had not articulated.

**A3. The insight implicates this brand.**
FAIL if it would work equally well for any competitor.

**A4. The proposition is one sentence and is not copy.**
FAIL if it carries two ideas, or if it reads like a tagline.

## B. The idea

**B1. It is a platform, not an execution.**
Test: write a brief for a second execution from it. If you cannot, FAIL.

**B2. It survives substitution.**
Put a named competitor on it. If it still reads as true, FAIL.

**B3. It survives three years.**
FAIL if it depends on a moment, a trend, or a season that expires.

**B4. It is livable.**
Name what the company does differently on Monday. If nothing, FAIL.

**B5. It is contestable.**
Could an intelligent colleague argue against it? If nobody could, it is a
category convention restated. FAIL.

## C. The set

**C1. Territories are genuinely divergent.**
Take any two. If they could merge without losing anything, FAIL. This checks
diversity collapse, which is the specific failure mode of generated idea sets.

**C2. Each territory came from a stated constraint.**
FAIL if the territories were generated freely rather than under incompatible
constraints.

**C3. At least one territory is uncomfortable.**
If every option is safe, the set has not explored the space. FAIL.

## D. Integrity

**D1. No invented facts.**
Zero fabricated market data, audience research, competitor claims, or results.
One invented fact fails the whole deliverable.

**D2. Effectiveness claims are graded.**
Any claim about what works cites a real source or is stated as convention. FAIL
on 60/40, the awards-effectiveness inversion, or any untraceable statistic.

**D3. Assumptions are disclosed.**
Anything assumed rather than supplied appears in the delivery note.

**D4. A recommendation is made.**
A menu with no point of view is not strategy. FAIL if no territory is
recommended and justified.

## Scoring

Fix all FAILs, re-score. Maximum two rounds. Anything still failing is a real
constraint: report it plainly rather than looping or hiding it.
