# Rubric: Marketing Architecture Audit

Score every line PASS or FAIL. No partial credit. Quote evidence from the draft.
Burden of proof is on PASS.

## A. Inputs

**A1. All seven questions were asked and answered, or gaps are named.**
FAIL if the audit proceeded on assumed answers without saying so.

**A2. Scope was checked before running.**
Teams of 1 to 2 people, or solo founders, are out of scope and should have been
redirected. FAIL if a full audit was run on an org the skill states it does not
serve.

**A3. No invented numbers.**
Zero fabricated salaries, budgets, headcounts, or benchmarks. If the user could
not supply a figure, the draft points to a public benchmark rather than
estimating. One invented number fails the whole deliverable.

## B. Classification

**B1. Every role is classified with its reasoning shown.**
FAIL on any role assigned to A, B, or C without the judgment sentence that
justified it.

**B2. Classification follows the stated evidence, not the conclusion.**
Check for roles pushed into Category C to make the headline more dramatic. FAIL
if a classification is not supported by the user's own Q3 answer.

**B3. Hybrid roles specify which slice survives.**
Category B without a stated judgment percentage and what it covers is a FAIL.

**B4. Uncertainty is marked.**
Roles the user described vaguely are flagged as provisional rather than
classified confidently. FAIL on false precision.

## C. Recommendations

**C1. Each recommended system is named and matched to a specific role.**
FAIL on generic "use automation" or "adopt AI tools".

**C2. Capability claims are honest.**
Systems do coordination. Humans do taste, relationships, and non-obvious
judgment. FAIL on any claim that a system replaces judgment work.

**C3. The default is architecture, not headcount reduction.**
The report explicitly states that most Category C people can move into A or B
work. FAIL if the output reads as a layoff plan.

**C4. Cost claims are traceable.**
Any saving figure derives from numbers the user supplied. FAIL on modelled
savings presented as findings.

## D. Usability

**D1. The redundancy map is specific enough to act on.**
FAIL if the user could not take a decision from it on Monday.

**D2. Assumptions and confidence are disclosed.**
The delivery note names what was assumed and which classifications are firm.

## Scoring

Fix all FAILs, re-score. Maximum two rounds. Report anything still failing
plainly.
